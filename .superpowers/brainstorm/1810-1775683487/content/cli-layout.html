CLI Layout — How should parallel tenants display?

Each tenant streams work in real-time. How should multiple tenants share the screen?

A

Stacked Panels

Each tenant gets a bordered panel. All visible at once, scrolling vertically. Like docker-compose logs with labels.

backend_engineer running
▸ Writing REST API routes...
▸ ✓ Checkpoint routes_defined passed
frontend_engineer waiting on backend_engineer
⏳ Blocked by dependency
B

Focused View + Status Bar

One active tenant streams at a time (most interesting one). A compact status bar at the bottom shows all tenants. Like Claude Code's single-agent focus with a multi-agent twist.

❯ backend_engineer
I'll create the Express server with JWT auth middleware...
✓ file_write src/server.js
Now setting up the routes...
● backend   ○ frontend   ○ tester
C

Timeline Feed

All tenant events interleave chronologically in one stream, color-coded by tenant. Like a unified activity log. Simpler but can get noisy with many tenants.

[backend] Writing REST API routes...
[frontend] Waiting for backend artifacts...
[backend] ✓ file_write src/server.js
[backend] Setting up auth middleware...
[backend] ✓ Checkpoint routes_defined passed
[frontend] Starting React component design...
